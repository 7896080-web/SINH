# Стартовый промпт — Фаза 1 (MVP без ML)

Прочитай `CLAUDE.md`, затем `docs/tz/00-index.md` и разделы 3, 4, 6, 12 (`docs/tz/`). Реализуй Фазу 1 из раздела 12.

## Объём
1. Репозиторий: структура пакета (`app/`, `app/integrations/{lamoda,onec,...}`, `app/forecast/`, `app/web/`, `migrations/`, `tests/`), `.env.example`, README с запуском.
2. БД: применить `docs/schema.sql` целиком (миграциями), проверить что накатывается на чистый PostgreSQL.
3. Загрузка справочника из Excel-карты мэппинга (у пользователя уже есть): модели, цветоразмерные SKU, **пул баркодов**.
4. Интеграция 1С: чтение остатков ЦС и продаж/розницы из файлов FTP-моста (формат уточнить у пользователя по образцам).
5. Lamoda Seller API v2: авторизация с обновлением токена, опрос остатков FBO и заказов (`GET /v2/orders` по `updatedAtFrom`), пагинация, ретраи, единый разбор ошибок. Только v2.
6. Расчёт без ML: плоское сглаживание спроса + точка заказа/страховой запас; цензурирование по stockout минимально.
7. Две страницы (FastAPI + простой UI) с Excel-выгрузкой по раздел 6: закупка у поставщиков; поставка на FBO (остаток ЦС, остаток FBO, рекомендация, поле подтверждённого количества, «Собрать поставку» → Excel в том же формате).
8. Тесты: маппинг по любому баркоду из пула, пересчёт копеек, пагинация, идемпотентность заказов.

## Вне объёма Фазы 1
SBC/бэктест, DeepAR, вебхуки, оптимизация цен, WB/Ozon/сайт, достоверность % (поле-заглушка).

## Порядок
Сначала план и список вопросов по форматам файлов 1С, затем реализация и демонстрация на тестовых данных. Критерий готовности — раздел 12, Фаза 1.
