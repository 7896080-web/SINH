## 11. Академические и открытые источники, использованные в проектировании

**Методы (академическая литература):**
- **Newsvendor model** (Arrow et al. 1951, восходит к Edgeworth 1888) — критическая доля для объёма первой поставки новинок, раздел 5.6
- **Croston (1972) / Syntetos-Boylan Approximation (2001)** — прогноз прерывистого спроса, раздел 5.2
- **Johnston & Boylan (1996), Syntetos-Boylan-Croston (2005)** — классификация типа спроса по ADI×CV² (Smooth/Irregular/Intermittent/Lumpy), раздел 5.2
- **Nahmias (1994), Wecker (1978)** — censored demand estimation, академическое обоснование коррекции спроса на stockout, раздел 5.1; риск spiral-down эффекта и Tobit Exponential Smoothing как путь апгрейда
- **Cycle service level (Type 1) vs fill rate (Type 2)** — стандартное разделение в теории управления запасами, применено в разделах 5.2/5.5 (буфер) и 5.8 (мониторинг)

**Отраслевой разбор (проверка формул на практике):**
- **Forecast NOW!** (fnow.ru) — детальный разбор формулы страхового запаса `k×σ×√L`: незащищённое окно должно включать интервал пересмотра, σ считается по ошибке прогноза (не по сырым продажам), расширенная формула при нестабильном lead time, фильтр выбросов 3σ — все учтено в разделе 5.5. Также подтверждение, что классические методы (SMA, экспоненциальное сглаживание, Хольта-Винтерса) дают одно число без распределения, что ограничивает их применимость для около 94% ассортимента с негладким спросом
- **Beltel Datanomics** — эмпирическое сравнение Croston/TSB против Naive/SES на реальных данных оптово-розничной сети: TSB даёт лучшие результаты по большинству метрик, подтверждён выбор TSB как предпочтительного метода для Lumpy-категории (раздел 5.2); также источник метрик дефицита/профицита (раздел 5.8) и метода двухвыборочного t-теста для обнаружения промо-каннибализации между разными артикулами (раздел 5.3)

**Открытый код и референсы (для этапа реализации):**
- **`Nixtla/statsforecast`** (Apache 2.0) — готовые модели `CrostonSBA`, `TSB`, `IMAPA`, `ADIDA` для прерывистого спроса, раздел 5.2/7
- **`awslabs/gluonts`** (Apache 2.0, бесплатно) — реализация DeepAR (Salinas et al., 2017/2019, глобальная вероятностная модель поверх RNN, JMLR) — шестой кандидат бэктест-турнира и альтернативный источник для новинок, раздел 5.2/5.6/7; на масштабе AWER обучается на CPU, GPU не обязателен
- **`wbsdk`** (Python) — готовый клиент Statistics API Wildberries, раздел 4/7
- **`pavelmaksimov/tapi-yandex-direct`, `pavelmaksimov/tapi-yandex-metrika`** (MIT) — готовые Python-клиенты для API Директа/Wordstat и Метрики, раздел 4/7
- **`lamoda/seller-center-sdk-php`, `lamoda/lamoda-b2b-platform.php-sdk`** — официальные репозитории Lamoda (Global Fashion Group), авторитетный референс по структуре эндпоинтов B2B Platform REST API
- **`eslazarev/wildberries-sdk`** и открытые MCP-серверы для WB/Ozon Seller API — структурное подтверждение, что подход из раздела 4 (остатки, воронка продаж как отдельные отчётные эндпоинты) — общая практика API маркетплейсов, не частный случай Lamoda
- **`samirsaci/inventory-periodic`** — референс реализации periodic review policy на Python, релевантно логике частоты пересмотра по сегменту ABC×XYZ (раздел 5.2)
