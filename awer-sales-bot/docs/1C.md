# Внешняя обработка 1С «ВыгрузкаПродажДляБота»

Исходники: `onec/ВыгрузкаПродажДляБота/МодульОбъекта.bsl`, `МодульФормы.bsl`.
Собирается в Конфигураторе в файл `ВыгрузкаПродажДляБота.epf` (бинарник в git не храним).

## Что выгружает

CSV (UTF-8, разделитель `;`) — строки чеков за период:

```
Дата;Магазин;Продавец;Чек;Номенклатура;Номенклатурная группа;Количество;Сумма
17.10.2026;Город;Букалова Юлия;0000123;805 AMSTERDAM ПитБуль Брюки/Шнурок BLACK;Брюки/Шнурок;1;3535.53
17.10.2026;МСЛ;Букалова Юлия;В-0000017;...;...;-1;-3600
```

Сумма — со скидкой; возвраты — с минусом (чек с префиксом `В-`). По умолчанию только чеки
закрытых смен (статус «Архивный» после «Отчета о розничных продажах») — это и есть «день закрыт».
Повторная выгрузка безопасна: бот заменяет данные (день, магазин) целиком.

## Сборка в Конфигураторе

1. **Файл → Новый… → Внешняя обработка**. Имя: `ВыгрузкаПродажДляБота`, синоним «Выгрузка продаж для бота».
2. **Реквизиты** обработки:
   | Имя | Тип |
   |---|---|
   | ДатаНачала | Дата (дата) |
   | ДатаОкончания | Дата (дата) |
   | КаталогВыгрузки | Строка (неогр.) |
   | АдресСервиса | Строка (неогр.) |
   | ТокенСервиса | Строка (неогр.) |
   | ТолькоЗакрытыеСмены | Булево |
3. **Модуль объекта**: вставить `МодульОбъекта.bsl` целиком.
4. **Форма** → «Добавить» → форма обработки (управляемая). Перетащить реквизиты на форму.
   Добавить команду формы `Выгрузить` (действие — процедура `Выгрузить`) и кнопку.
   **Модуль формы**: вставить `МодульФормы.bsl`.
5. **Проверить имена метаданных вашей конфигурации** (места с пометкой `ПРОВЕРИТЬ`):
   * `Документ.ЧекККМ.Товары`, `Документ.ЧекККМВозврат.Товары`;
   * колонка продавца в строке (`Товары.Продавец`) — если продавец в шапке, заменить на `Товары.Ссылка.Продавец`
     или `Товары.Ссылка.Кассир`;
   * `Товары.Ссылка.Магазин`, `Перечисления.СтатусыЧековККМ.Архивный/Пробит`;
   * `Номенклатура.НоменклатурнаяГруппа` (у вас в отчёте «Продажи» есть «Номенклатура.Номенклатурная группа»);
   * если продавца в чеке нет — вариант Б в тексте запроса (`РегистрНакопления.Продажи`).
   Проще всего: открыть в Конфигураторе ветку Документы → ЧекККМ → Табличные части → Товары.
6. Проверка: запустить 1С:Предприятие, **Файл → Открыть** → `.epf`, выгрузить вчера в папку и
   выполнить `awer-bot import-sales <файл>` — увидеть число строк и продавцов.
7. **Файл → Сохранить как** → `ВыгрузкаПродажДляБота.epf`.

## Автозапуск каждый день

**Вариант 1 — через БСП (рекомендуется).** НСИ и администрирование → Печатные формы, отчеты и обработки →
Дополнительные отчеты и обработки → Добавить из файла → выбрать `.epf`. В карточке:
размещение (раздел), команда «Выгрузить продажи за вчера» → **Настроить расписание**: ежедневно,
после закрытия смен (например, 23:30 и повтор в 07:00). Папку/адрес задать в функциях
`КаталогПоУмолчанию()` / `АдресПоУмолчанию()` / `ТокенПоУмолчанию()` в модуле объекта (до сборки .epf).
Для файловой базы регламентные задания выполняются, пока открыт хотя бы один клиент
(или настроить запуск по расписанию Windows: `1cv8.exe ENTERPRISE /F"путь_к_базе" /N"Пользователь" /P"..." /Execute"...epf"` —
тогда добавить в модуль формы автозапуск выгрузки при открытии с параметром `/C"auto"`).

**Вариант 2 — вручную**: открывать обработку утром и нажимать «Выгрузить».

## Куда кладёт файл

* `КаталогВыгрузки` — папка `data/inbox` бота (или сетевая `\\сервер\awer-inbox`). Бот забирает файлы при ежедневном запуске.
* `АдресСервиса` + `ТокенСервиса` — если бот на другом компьютере: `http://<ip>:8080/api/upload`,
  токен = `UPLOAD_TOKEN` из `.env`. Бот сразу импортирует файл и отвечает числом строк.
  Админка тогда запускается с `--host 0.0.0.0`; закройте порт снаружи сети.
