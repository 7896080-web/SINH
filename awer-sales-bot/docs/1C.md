# Внешняя обработка 1С «ВыгрузкаПродажДляБота»

База: обычное приложение (обычные формы). Продажи по продавцам есть в двух местах:
* **чеки ККМ** (`Документ.ЧекККМ`) — информативнее: номер чека и время → средний чек, вещей в чеке,
  доля чеков «одна вещь» по каждому продавцу, лучшие часы;
* **«Отчет о розничных продажах»** (ОРП) — сводно по кассе за смену: продавец в строке есть, номера чека нет.

Обработка умеет оба источника (реквизит `Источник` = «Чеки» / «ОРП»). **Начните с «Чеки»**; если чеки после
закрытия смены в базе не хранятся (список «Чеки ККМ» за прошлые дни пуст) — переключите на «ОРП».
Бот сам понимает, что пришло: при «ОРП» средний чек и вещей в чеке считает по магазину, а по продавцу —
по покупкам клиентов с дисконтной картой (строки одной карты в одном документе = одна покупка).

Исходники: `onec/ВыгрузкаПродажДляБота/МодульОбъекта.bsl`, `МодульФормы.bsl`.
Собирается в Конфигураторе в `ВыгрузкаПродажДляБота.epf` (бинарник в git не храним).

## Что выгружает (CSV, UTF-8, `;`)

| Файл | Содержимое | Зачем |
|---|---|---|
| `sales_*.csv` | Дата;Время;Склад;Документ;Чек;Продавец;Номенклатура;Номенклатурная группа;Количество;Цена;Сумма;Скидка;Ручная скидка %;Дисконтная карта | план, ступени, качество продаж; возвраты с минусом; пустой продавец → «(без продавца)» (видно владельцу) |
| `orp_docs_*.csv` | Дата;Магазин;Касса;Документ;Чеков;Чеков возврата;Выручка | признак «смена закрыта» (проведённый ОРП), средний чек магазина |
| `stock_*.csv` | Дата;Склад;Номенклатура;Номенклатурная группа;Характеристика;Остаток | советы только по товару в наличии; владельцу — «битые» размеры и залежавшийся товар |
| `arrivals_*.csv` | Дата;Склад;Документ;Номенклатура;Номенклатурная группа;Характеристика;Поступило | продавцам утром — что пришло нового |

Скидка = Цена × Количество − Сумма. Ручная скидка — по колонке «% Руч. ск.» (владельцу, продавцам не показывается).
Остатки и поступления — только складов магазинов: реквизит `СкладыМагазинов` (подстроки через `;`, по умолчанию
`ГОРОД;МСЛ`). Магазин определяется по складу/кассе через `config.yaml → onec.store_map`.

## Сборка в Конфигураторе

1. **Файл → Новый… → Внешняя обработка.** Имя `ВыгрузкаПродажДляБота`, синоним «Выгрузка продаж для бота».
2. **Реквизиты:** `ДатаНачала` (Дата, состав «Дата»), `ДатаОкончания` (Дата), `КаталогВыгрузки` (Строка, неогр.),
   `Источник` (Строка 10: «Чеки» / «ОРП»), `СкладыМагазинов` (Строка, неогр.).
3. **Действия → Открыть модуль объекта** — вставить `МодульОбъекта.bsl`.
4. **Формы → Добавить** — тип «Форма обработки», **обычная форма**. Разместить поля реквизитов,
   кнопку «Выгрузить» с действием `КнопкаВыгрузитьНажатие`. В модуль формы вставить `МодульФормы.bsl`.
   В свойствах формы событие «ПриОткрытии» → `ПриОткрытии`.
5. **Сверить имена метаданных** (пометки `ПРОВЕРИТЬ`):
   * `Документ.ЧекККМ`: ТЧ `Товары` (`Продавец`, `Цена`, `Сумма`, `ПроцентСкидкиНаценки`), шапка `Склад`, `КассаККМ`,
     `ДисконтнаяКарта`, `ВидОперации` (Продажа/Возврат), статус `СтатусЧекаККМ` (Пробитый/Архивный);
     если продавец в шапке чека — `Т.Ссылка.Продавец` или `Т.Ссылка.Кассир`;
   * `Документ.ОтчетОРозничныхПродажах`: шапка `КассаККМ`, `КоличествоЧеков`, `КоличествоЧековВозврата`;
     ТЧ `Товары` (`Продавец`, `Склад`, `ДисконтнаяКарта`, `ПроцентСкидкиНаценки`) и `ВозвращенныеТовары`;
   * `РегистрНакопления.ТоварыНаСкладах` (`Склад`, `Номенклатура`, `ХарактеристикаНоменклатуры`, `Количество`);
   * `Номенклатура.НоменклатурнаяГруппа`.
   Быстрая проверка запроса — Конструктор запроса (ПКМ по тексту запроса → Конструктор запроса): если поле не найдено,
   конструктор подсветит ошибку.
6. Сохранить: **Файл → Сохранить как** → `C:\awer-sales-bot\onec\ВыгрузкаПродажДляБота.epf`.
7. Проверка: в 1С:Предприятии **Файл → Открыть** → `.epf` → период «вчера» → «Выгрузить».
   В папке появятся два файла; затем `awer-bot import-sales` покажет число строк и продавцов.

## Автозапуск каждый день

Планировщик заданий Windows → «Создать задачу»: ежедневно, например в 07:30 (после закрытия смен накануне).
Действие:
```
"C:\Program Files\1cv8\8.3.xx.xxxx\bin\1cv8.exe" ENTERPRISE /F"D:\Базы\Магазин" /N"Бот" /P"пароль"
   /Execute"C:\awer-sales-bot\onec\ВыгрузкаПродажДляБота.epf" /C"АВТО" /DisableStartupMessages
```
(для серверной базы вместо `/F` — `/S"сервер\база"`). Для запуска заведите в 1С отдельного пользователя «Бот»
с правом чтения ОРП. С параметром `/C"АВТО"` обработка выгружает вчера и позавчера и закрывает 1С.
Время запуска 1С ставьте раньше `schedule.daily_send_time` бота (по умолчанию 09:30); если файла нет — бот ждёт
и повторяет каждые 30 минут до 13:00.

Ручной вариант: утром открыть обработку и нажать «Выгрузить».

## Если 1С и бот на разных компьютерах

`КаталогВыгрузки` — сетевая папка (`\\сервер\awer-inbox`), которую бот видит как `onec.inbox`.
(Есть и приём файла по HTTP — `POST /api/upload` с заголовком `X-Token`, если понадобится.)
