# Установка на сервер Windows

Бот ставится на тот же сервер, где работают 1С и Sync Admin. Всё делается через удалённый рабочий стол (RDP)
под учётной записью администратора. Время — около получаса, из них ждать — 5–10 минут.

**Что получится:**

| Что | Где | Когда работает |
|---|---|---|
| Служба **AwerSalesBot** — админка и бот MAX | `C:\awer-sales-bot`, админка http://127.0.0.1:8080 (только с сервера) | всегда, запускается вместе с Windows |
| Задача **AwerSalesBot-1C** — выгрузка из 1С | Планировщик заданий | каждый день в 07:30 и повтор в 08:30 |
| Задача **AwerSalesBot cloud backup** — копия базы | `C:\awer-sales-bot\backups` и Selectel | каждый день в 05:00 |

Рассылка продавцам — в 09:30 за вчерашний день.

## 0. Что приготовить

- Архив `awer-sales-bot-ДАТА.zip`.
- Интернет на сервере: установщик скачает Python (если его нет) и библиотеки.
- **Обработку 1С `ВыгрузкаПродажДляБота.epf` нужно собрать заново** из модулей нового архива (`docs\1C.md`,
  «Сборка»): с 19.10.2026 она выгружает и строки «Отчётов о розничных продажах» (по ним считаются деньги), и чеки
  (средний чек, вещей в чеке). Прежняя `.epf` в `C:\sync_admin\1c` выгружает только чеки — по ней бот денег не
  посчитает. Готовую положите в `C:\awer-sales-bot\onec\` (установщик возьмёт её и сам, если она лежит рядом).
- **Историю продаж с 01.10.2024 выгрузите новой обработкой** (раздел 4). Файлы истории, выгруженные раньше, бот
  загрузит только как чеки: план по ним не посчитается.
- Токены ботов MAX. Они появятся после модерации, их можно вписать позже: без них работает админка.

## 1. Установка

1. **Перенесите архив на сервер.** На своём компьютере щёлкните архив правой кнопкой → «Копировать», в окне
   удалённого рабочего стола щёлкните по рабочему столу сервера → «Вставить».
2. **Распакуйте:** правой кнопкой по архиву → «Извлечь все…» → «Извлечь».
3. **Откройте PowerShell от имени администратора:** «Пуск» → наберите `PowerShell` → правой кнопкой →
   «Запуск от имени администратора».
4. **Запустите установку** (подставьте имя распакованной папки):
   ```
   cd $HOME\Desktop\awer-sales-bot-ДАТА\awer-sales-bot
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Admins "Эльвина Абдулиннанова,Букалова Юлия"
   ```
   `-Admins` — старшие продавцы, имена как в 1С, одной строкой через запятую. Если что-то не так, роль можно
   поменять позже в админке, в разделе «Продавцы».
5. **Запишите пароль админки.** Установщик покажет его зелёным сразу, как создаст, и ещё раз в конце. Пароль
   хранится в `C:\awer-sales-bot\.env`.

Что делает установщик по шагам:
- ставит Python 3.12, если подходящего нет;
- копирует программу в `C:\awer-sales-bot` (папку `data\inbox` с файлами 1С не трогает). Менять файлы в этой
  папке могут только система и администраторы — служба работает от имени системы;
- ставит библиотеки и создаёт `config.yaml` и `.env` с паролем. Доступ к `.env` есть только у системы и администраторов;
- проверяет программу тестами (1–2 минуты);
- создаёт базу, регистрирует службу AwerSalesBot через NSSM, как у Sync Admin, и проверяет, что отвечает именно она;
- загружает файлы из `data\inbox`. История за два года грузится несколько минут;
- создаёт задачу копии базы и сразу делает первую копию;
- в конце показывает сводку состояния.

Если тесты не прошли при первой установке, установщик об этом предупредит и продолжит: данных в системе ещё нет.
Пришлите этот вывод разработчику.

## 2. Админка

На сервере откройте браузер: **http://127.0.0.1:8080**, логин `admin`, пароль из шага 1.5. Админка открывается
только на самом сервере, как и у Sync Admin.

## 3. Проверить данные

1. **«График работы» → «Закрытые дни».** Бот покажет дни истории, по которым из 1С нет ни одной продажи:
   01.01.2025, 01.01.2026 и 25.06.2026. Если магазины в эти дни не работали, нажмите «Магазины были закрыты»
   у каждого. Иначе бот считает такой месяц неполным и завышает его.
2. **«Продавцы» → «Имена в 1С».** Проверьте, нет ли одного человека под двумя написаниями. «Одежда сотрудникам»,
   «Стажер» и «Татьяна» (технические продажи) — служебные записи: их продажи входят в выручку магазина, но плана
   и ставки у них нет.
3. **«Продавцы».** После загрузки истории за два года там около 40 человек, включая тех, кто давно ушёл.
   Отметьте ушедших «Уволить», чтобы в списке остались только работающие. Их история продаж сохранится.
   Проверьте **«Обращение»**: бот здоровается по нему. У тех, кто записан в 1С как «Имя Фамилия» (например,
   «Эльвина Абдулиннанова»), впишите имя, иначе бот напишет «Доброе утро, Абдулиннанова!».
4. **«Проверка плана»** с 2026-08 по 2026-10 — какой план бот поставил бы каждому и сколько продано.
5. **Сверка с 1С.** После загрузки истории `awer-bot import-sales` (раздел 4) печатает дни, где строки «Отчёта о
   розничных продажах» не сходятся с его итогом больше чем на 1 000 ₽. Таких дней быть не должно; если есть —
   пришлите вывод разработчику. Каждое утро бот делает ту же сверку сам и пишет вам, если что-то не сошлось.

## 4. Если файлов истории в `data\inbox` нет

1. Откройте 1С как обычно, затем «Файл» → «Открыть» → `C:\awer-sales-bot\onec\ВыгрузкаПродажДляБота.epf`
   (собранная заново, раздел 0).
2. Выберите «Выгрузить продажи за период», укажите период с 01.10.2024 по вчерашний день. Появятся пять файлов:
   `orp_docs_…`, `sales_…` (строки отчётов — деньги), `receipts_…` (чеки), `stock_…`, `arrivals_…`.
   Лучше делать вечером: выгрузка за два года занимает несколько минут.
3. Загрузите файлы (PowerShell от администратора):
   ```
   cd C:\awer-sales-bot
   .\.venv\Scripts\awer-bot.exe import-sales
   ```
   Пока не вписаны токены ботов (раздел 6), сама служба файлы из `data\inbox` не забирает. После этого она делает
   это каждое утро сама.

## 5. Ежедневная выгрузка из 1С

Подробно — в `docs\1C.md`, раздел «Автозапуск каждый день». Коротко:

1. **В Конфигураторе** заведите пользователя 1С «Бот» с паролем: роль только на чтение и право открывать внешние
   обработки, **снимите «Защита от опасных действий»**. Вход — по имени и паролю, как у Sync Admin.
   «Аутентификацию операционной системы» не включайте: тогда любой, кто откроет 1С под вашей учётной записью
   Windows, войдёт как «Бот».
2. **PowerShell от имени администратора**, под учётной записью, под которой вы обычно входите на сервер:
   ```
   cd C:\awer-sales-bot
   powershell -ExecutionPolicy Bypass -File scripts\install-1c-task.ps1 -Base "сервер-1С\имя-базы"
   ```
   В `-Base` впишите то же, что стоит после `/S` в задаче обмена Sync Admin: Планировщик заданий → задача
   Sync Admin → «Действия». Скрипт спросит пароль пользователя 1С «Бот»; он будет виден в свойствах задачи,
   как у Sync Admin.
3. **Проверка:** Планировщик заданий → «AwerSalesBot-1C» → «Выполнить». Через 1–2 минуты в `data\inbox` появятся
   файлы за вчера и позавчера.

Задача работает, только пока на сервере кто-то вошёл, как и обмен Sync Admin: толстому клиенту 1С нужен рабочий
стол. Друг другу задачи не мешают.

## 6. Боты MAX (после модерации)

1. **«Бот MAX»:** вставьте токены ботов «План» и «Обучение» → «Сохранить и проверить связь». Сверху админки
   появится строка «бот на связи».
2. **Владелец:** «Бот MAX» → «Подключить владельца» → отсканируйте QR телефоном → бот пришлёт подтверждение.
   С этого дня вам приходят сводки и предупреждения.
3. **Продавцы:** «Продавцы» → «Выдать код» → карточка с QR. Продавец сканирует QR и отправляет боту код.
   Сразу после подключения бот пришлёт памятку «Как читать сообщения бота»: что значат план, «до базы», ступени,
   темп и показатели. Её же продавец получит по команде /help.

## 7. Октябрь — пробный, ноябрь — первый расчётный

В `config.yaml` стоит `first_month: "2026-11"`. Подключённые в октябре продавцы получают план октября и утренние
сообщения с пометкой «пробный месяц», но итогов октября со ставкой бот не подводит и не рассылает. 1 ноября,
когда придёт выгрузка за 31 октября, бот зафиксирует план на ноябрь и разошлёт его каждому подключённому;
подключившиеся позже получат свой план при подключении к утренней рассылке.

**График работы важен.** Рабочие дни у всех, и у старших, считаются по графику: от них зависят план на месяц,
«до базы» и доля ставки. До 1-го числа заполните «График работы» на месяц. Если продавец продал в день, которого
нет в его графике, бот спросит вас в «Графике работы» (и строкой в утренней сводке): «Работал(а) — добавить в
график» (вышел на замену) или «Не работал(а)» (покупатель забрал отложенное). Продажа в обоих случаях остаётся у
продавца. Без графика бот считает рабочими дни, когда продавец что-то продал.

Ещё раз посмотрите «Настройки месяца»: коэффициент год к году и шаг 15 %. Шаг вписывается в процентах — «15».

**Итоги месяца** бот подводит сам, когда в 1С закрыты все дни месяца по обоим магазинам, и только тогда рассылает
продавцам. Пока какого-то дня нет, он каждое утро пишет вам, какого. Кнопка «Посчитать итоги» до этого даёт
предварительные итоги — посмотреть; продавцам она ничего не отправляет.

Новичок появился в середине месяца — бот ставит ему план новичка и пишет вам. Сильному новичку впишите план
сам: «Настройки месяца» → «План вручную» → «Сохранить ручные планы». Ручной план применяется сразу и только к нему.

## 8. Копии базы

- Каждый день в 05:00 делается снимок базы с проверкой целостности в `C:\awer-sales-bot\backups`.
  Снимки хранятся 30 дней, затем уходят в Selectel: `selectel:awer-backups/awer_sales_bot`, там тоже 30 дней.
- Ключ Selectel установщик берёт из `C:\FinanceBot\rclone.conf`: ключ у всех программ один, а файл остаётся на
  сервере. Если такого файла не было, снимки делаются только на сервере, а задача копии завершается с кодом 2 —
  `status.ps1` это покажет. Чтобы включить облако, скопируйте `rclone.conf` любой программы из `BACKUPS.md` в
  `C:\awer-sales-bot\rclone.conf` и запустите задачу копии (`Start-ScheduledTask "AwerSalesBot cloud backup"`):
  она сама закроет доступ к файлу для всех, кроме системы и администраторов.
- Журнал: `C:\awer-sales-bot\logs\cloud_copy.log`.
- **Восстановить** (PowerShell от администратора):
  ```
  Stop-Service AwerSalesBot
  Copy-Item C:\awer-sales-bot\backups\awer-ГГГГММДД-ЧЧММ.db C:\awer-sales-bot\data\awer.db -Force
  Remove-Item C:\awer-sales-bot\data\awer.db-wal, C:\awer-sales-bot\data\awer.db-shm -ErrorAction SilentlyContinue
  Start-Service AwerSalesBot
  ```
  Пропадёт всё, что было после снимка, в том числе подключения продавцов и ручные планы.

## 9. Обновление до новой версии

Распакуйте новый архив и запустите из него ту же команду, что в разделе 1 (без `-Admins`):
```
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```
Установщик остановит службу, сделает снимок базы и сохранит прежний код в `backups\code-…`. Потом заменит код,
прогонит тесты и запустит службу на прежнем порту. Если тесты не прошли или служба не ответила, он вернёт
прежнюю версию и запустит её. `.env`, `config.yaml` и собранная обработка `.epf` не меняются; новые файлы 1С из
`data\inbox` служба загрузит сама при утренней рассылке. Новые настройки из `config.example.yaml` в ваш
`config.yaml` сами не попадают — о нужных разработчик скажет отдельно.

## 10. Если что-то не так

Запустите проверку состояния и пришлите весь вывод:
```
powershell -ExecutionPolicy Bypass -File C:\awer-sales-bot\scripts\status.ps1
```
Она показывает службу и задачи, последний день данных 1С по магазинам, дни без данных, зафиксирован ли план
месяца, связь с MAX, утреннюю рассылку, последнюю копию базы и хвосты журналов.

| Что сделать | Команда (PowerShell от администратора) |
|---|---|
| Перезапустить бота и админку | `Restart-Service AwerSalesBot` |
| Остановить / запустить | `Stop-Service AwerSalesBot` / `Start-Service AwerSalesBot` |
| Журнал службы | `Get-Content C:\awer-sales-bot\logs\service.err.log -Tail 50 -Encoding UTF8` |
| Рассылка без отправки, посмотреть тексты (на копии базы — ничего не меняет) | `cd C:\awer-sales-bot; .\.venv\Scripts\awer-bot.exe daily --dry-run --force` |
| Копия базы сейчас | `Start-ScheduledTask "AwerSalesBot cloud backup"` |
| Забыли пароль админки | откройте `C:\awer-sales-bot\.env` в Блокноте от администратора — строка `ADMIN_PASSWORD=` |

После правки `.env` вручную нужен перезапуск: `Restart-Service AwerSalesBot`. Токены, вписанные на странице
«Бот MAX», действуют без перезапуска. Не запускайте `awer-bot bot` вручную, пока работает служба: второй бот
слал бы каждое сообщение дважды, поэтому он и не запустится.
