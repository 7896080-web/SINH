# awer-sales-bot

Индивидуальные планы продавцов AWER и ежедневные сообщения в мессенджер MAX — два бота: «План» (план и личные
показатели) и «Обучение» (уроки, тесты, база знаний), см. docs/MAX.md.

Каждое утро продавец получает: базовый план на месяц, сколько осталось до базы и до следующей ступени
(+5 000 ₽ за каждые 15 % сверх плана), продажи и вещи за рабочий день, среднюю цену вещи, средний чек и вещей в чеке
по магазину и совет, как продать больше.
Владелец — сводку по всем. Данные — из 1С (внешняя обработка), настройки — в веб-админке.

Правила расчёта: [docs/SPEC.md](docs/SPEC.md) · 1С: [docs/1C.md](docs/1C.md) · бот MAX: [docs/MAX.md](docs/MAX.md)

## Установка (Windows, на компьютере с 1С или рядом)

```powershell
# Python 3.11+  (https://www.python.org/downloads/ — галочка «Add to PATH»)
cd C:\awer-sales-bot
python -m venv .venv
.venv\Scripts\activate
pip install -e .[dev]
copy config.example.yaml config.yaml
copy .env.example .env      # вписать ADMIN_PASSWORD, UPLOAD_TOKEN; токены ботов — в админке «Бот MAX»
pytest -q                   # все тесты должны пройти
```

## Первый запуск

```powershell
awer-bot init-db
awer-bot import-history "D:\ЗП" --admins "Эльвина Абдулиннанова" "Букалова Юлия"   # история из ведомостей
awer-bot plan 2026-11                       # посмотреть расчёт плана
awer-bot web                                # админка http://127.0.0.1:8080 (admin / ADMIN_PASSWORD)
```

В админке: «Настройки месяца» — расчётный и ручной коэффициент год к году, шаг %, надбавка, база,
максимум, ручные личные планы → «Зафиксировать план». «Продавцы» — подключение новых к боту (карточка с QR-кодом),
роли, увольнение и возврат (docs/MAX.md). «Смены» — состав двух смен и магазин на неделю (по средам смены меняются магазинами), отметка сильных продавцов.
«График работы» — рабочие дни и магазин каждого продавца на месяц (норма 18, кнопки 3/2, 2/2, 5/2, «+ сб и вс»),
проверка минимума: в будни 2, в выходные 3 в каждом магазине; от рабочих дней впереди считается «до базы».

Каждый день: обработка 1С (по расписанию Windows) кладёт строки и шапки «Отчетов о розничных продажах» в `data/inbox` →
в 09:30 бот рассылает итоги за вчера.

```powershell
awer-bot import-sales                       # забрать файлы из data/inbox вручную
awer-bot daily --dry-run --force            # показать сообщения без отправки
awer-bot serve --host 127.0.0.1             # бот + админка (для постоянной работы)
awer-bot close-month 2026-11                # итоги и ставки → ведомость xlsx в админке
```

Служба Windows (автозапуск): `scripts/install-service.ps1`.

## Мотивация и обучение

Кроме плана и ставки бот:
* отмечает личные рекорды и серии;
* ставит цель недели по самому слабому показателю и раз в неделю присылает урок по этой теме с квизом из
  2 вопросов (кнопки в MAX);
* подсказывает, с чем предлагать новые поступления;
* новичку присылает программу первых 10 рабочих дней.

Владелец видит «Кого похвалить» с кнопкой «Похвалить», старшие и владелец по понедельникам получают листок для
разговоров 1:1. В админке «Обучение» правятся уроки, база знаний, тесты, опросы и чек-листы; «Задания» — рассылка
тестов, опросов и чек-листов в тестовые часы тем, у кого рабочий день; «Рейтинг» — информативный, без влияния на ЗП.
В боте «Обучение» — база знаний (/baza или любое слово: «кашемир», «пуховик») и раз в день карточка новинок из 1С: модель, бренд, цвет, размеры. На ставку всё это не влияет. Уроки — `content/lessons.yaml` (черновик, просмотрите до запуска),
правила — `docs/SPEC.md`, раздел «Мотивация и обучение».
