# Скилы Яндекс.Кит (сторонние)

Четыре скила из https://github.com/yandex/kit-skills, коммит `b009bef` (03.09.2026),
положены сюда, чтобы Claude Code видел их в каждой сессии этого репозитория:

- `yandex-kit-cabinet` — каталог, цены, остатки, заказы, промокоды через публичный API;
- `kit-store-checkup` — ревизия магазина, только чтение;
- `kit-storefront-constructor` — витрина: страницы, секции, публикация;
- `kit-custom-sections` — свои секции витрины, без сети и без токена.

Лицензия — MIT (`LICENSE-kit-skills`), уведомления — `NOTICES-kit-skills`.

Это чужой код: правки не вносим, обновляем целиком из репозитория-источника
(`git clone https://github.com/yandex/kit-skills && python3 install.py` или копией
каталогов `skills/*` сюда).

Важно: вместе с запросами к Кит скилы отправляют в Яндекс.Кит имя скила и текст
просьбы ассистенту (до 1000 символов). Отключается переменной окружения
`YANDEX_KIT_SKILLS_TELEMETRY_DISABLED=1`. Для работы нужен токен магазина:
кабинет Кит → Настройки → API → «Сгенерировать токен».

К программе sync_admin эти скилы отношения не имеют: она ходит в Kit своим
клиентом (`app/workers/platform_clients/kit.py`), а спека из
`yandex-kit-cabinet/references/openapi.json` — источник правды для него.
