# VPN WireGuard: машина с КриптоПро ↔ сервер

> **Не используется.** 29.09.2026 проверено: с сети машины с КриптоПро
> провайдер режет WireGuard (рукопожатие проходит, данные — нет). Рабочий
> путь — `SSH_TUNNEL.md`. Файл оставлен на случай смены провайдера.

Зачем и почему именно так — `ТЗ_МАРКИРОВКА.md`, п. 10.2. Здесь только шаги.

| | Сервер `136.243.92.95` | Машина с КриптоПро |
|---|---|---|
| Имя туннеля | `marking` | `marking` |
| Адрес в туннеле | `10.77.0.1/24` | `10.77.0.2/32` |
| Кто подключается | принимает | подключается сам |

**Закрытые ключи не покидают своих машин.** Обмениваются только открытыми
(строка «Открытый ключ» / «Public key» в окне туннеля). Ни закрытый ключ,
ни конфиг целиком в чат и в репозиторий не отправлять.

## 1. Сервер

1. WireGuard → «Добавить туннель» → «Добавить пустой туннель…». Имя `marking`.
   Программа сама создаёт пару ключей и вписывает строку `PrivateKey`.
   **Скопируйте «Открытый ключ» сервера** — он нужен на шаге 2.
2. Допишите конфиг так (строку `PrivateKey` не трогать):
   ```ini
   [Interface]
   PrivateKey = (уже вписан программой)
   Address = 10.77.0.1/24
   ListenPort = 51820

   [Peer]
   PublicKey = <открытый ключ машины с КриптоПро, шаг 2>
   AllowedIPs = 10.77.0.2/32
   ```
   Раздел `[Peer]` можно дописать после шага 2, когда будет ключ.
3. Открыть порт туннеля (PowerShell от администратора):
   ```powershell
   New-NetFirewallRule -DisplayName "WireGuard marking" -Direction Inbound -Protocol UDP -LocalPort 51820 -Action Allow
   ```
   Если в Hetzner Robot включён брандмауэр сервера — там тоже разрешить
   входящий UDP 51820.
4. «Сохранить» → «Подключить». Туннель, включённый в программе, становится
   службой Windows (`WireGuardTunnel$marking`) и поднимается сам после
   перезагрузки, без входа пользователя.

## 2. Машина с КриптоПро

1. WireGuard → «Добавить пустой туннель…», имя `marking`.
   **Скопируйте «Открытый ключ»** и впишите его на сервере (шаг 1.2,
   `[Peer] PublicKey`), затем на сервере «Сохранить».
2. Конфиг:
   ```ini
   [Interface]
   PrivateKey = (уже вписан программой)
   Address = 10.77.0.2/32

   [Peer]
   PublicKey = <открытый ключ сервера, шаг 1.1>
   Endpoint = 136.243.92.95:51820
   AllowedIPs = 10.77.0.1/32
   PersistentKeepalive = 25
   ```
   `AllowedIPs = 10.77.0.1/32` — в туннель идёт ТОЛЬКО программа на сервере;
   весь остальной интернет машины идёт как раньше.
3. «Сохранить» → «Подключить».

## 3. Проверка

На сервере — адрес появился:
```powershell
Get-NetIPAddress -IPAddress 10.77.0.1
```
На машине с КриптоПро — в окне WireGuard у туннеля растут счётчики
«Получено/Отправлено» и есть «Последнее рукопожатие» (несколько секунд
назад). Затем проверка плагина — `marking/tools/plugin_check.html`
(ТЗ, п. 10.2).

Нет рукопожатия — почти всегда закрыт UDP 51820 (брандмауэр Windows на
сервере или брандмауэр Hetzner) или перепутаны открытые ключи (у каждой
стороны в `[Peer]` должен стоять ключ ДРУГОЙ стороны).
