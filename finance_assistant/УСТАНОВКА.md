# Установка финансового помощника на сервер

Нужен сервер с Linux (Ubuntu или Debian), Python 3.10+ и доступом в интернет.
Подойдёт тот же VPS, где работает Sync Admin: боту не нужны ни домен,
ни открытые порты.

## Что подготовить

- **Токен бота**: в Telegram напишите @BotFather → `/newbot` → придумайте
  имя. Он пришлёт токен вида `123456:ABC-DEF…`.
- **Ключ Claude API**: https://platform.claude.com → API Keys → Create Key.
  Распознавание скриншотов оплачивается по тарифу API.

## Установка — 4 шага

1. **Загрузите архив на сервер** (с компьютера):
   ```bash
   scp finance-bot.zip root@ВАШ_СЕРВЕР:/root/
   ```
2. **Распакуйте и запустите установку** (на сервере):
   ```bash
   sudo apt install -y unzip python3-venv
   cd /root && unzip -o finance-bot.zip && cd finance_assistant
   sudo bash deploy/install.sh
   ```
   Скрипт поставит всё в `/opt/finance-bot` и скажет, что вписать в настройки.
3. **Впишите токен и ключ**:
   ```bash
   sudo nano /opt/finance-bot/.env
   ```
   Заполните `TELEGRAM_BOT_TOKEN` и `ANTHROPIC_API_KEY` (строку
   `ALLOWED_USER_IDS` пока оставьте пустой). Сохраните: Ctrl+O, Enter, Ctrl+X.
   Затем ещё раз:
   ```bash
   sudo bash deploy/install.sh
   ```
4. **Добавьте двух пользователей.** Каждый пишет боту в Telegram что угодно.
   Бот ответит «Доступ закрыт. Ваш Telegram id: 123456789». Впишите оба id:
   ```bash
   sudo nano /opt/finance-bot/.env      # ALLOWED_USER_IDS=123456789,987654321
   sudo systemctl restart finance-bot
   ```
   Теперь каждый добавляет свои карты: `/addcard Сбер 1234 Сбер`, для
   бизнес-счёта — `/addcard ПСБ 4987 ПСБ бизнес`. Справка по командам: `/help`.

## Потом

- **Обновление до новой версии**: распакуйте новый архив и снова выполните
  `sudo bash deploy/install.sh`. Перед заменой кода скрипт сделает бэкап,
  данные и `.env` не трогает.
- **Журнал работы**: `journalctl -u finance-bot -f`.
- **Бэкап**: каждый день в 03:30 в `/var/backups/finance-bot`, у каждого
  пользователя своим файлом. Сделать вручную:
  `sudo systemctl start finance-bot-backup`. Копию стоит также уносить
  с сервера.
- **Перезапуск**: `sudo systemctl restart finance-bot`.
- **Остановка**: `sudo systemctl stop finance-bot`.

## Первые дни

Посмотрите чек-лист первого запуска в конце `АУДИТ.md`. Распознавание ещё
ни разу не работало на ваших реальных скриншотах, поэтому первые 2–3 недели
сверяйте каждую карточку «✅ Записано» глазами.
