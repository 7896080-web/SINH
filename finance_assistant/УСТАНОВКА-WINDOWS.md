# Установка финансового помощника на сервер Windows

Подходит Windows Server 2016/2019/2022/2025 или Windows 10/11. Нужен доступ в
интернет. Домен не нужен. Всё делается через «Подключение к удалённому
рабочему столу» (RDP) под учётной записью администратора.

## Что подготовить

- **Токен бота**: в Telegram — @BotFather → `/newbot` → придумайте имя.
- **Токен тестового бота** (по желанию): ещё раз `/newbot`, например «Финансы ТЕСТ».
- **Ключ Claude API**: https://platform.claude.com → API Keys → Create Key.
- **Архив** `finance-bot.zip`.

## Установка

1. **Перенесите архив на сервер.** На своём компьютере нажмите на
   `finance-bot.zip` правой кнопкой → «Копировать». В окне удалённого рабочего
   стола щёлкните по рабочему столу сервера → «Вставить».
2. **Распакуйте**: правой кнопкой по архиву → «Извлечь все…» → «Извлечь».
   Появится папка `finance-bot`, в ней `finance_assistant`.
3. **Откройте PowerShell от имени администратора**: «Пуск» → наберите
   `PowerShell` → правой кнопкой → «Запуск от имени администратора».
4. **Запустите установку** (две команды):
   ```
   cd $HOME\Desktop\finance-bot\finance_assistant
   powershell -ExecutionPolicy Bypass -File deploy\windows\install.ps1
   ```
   Установщик сам поставит Python, если его нет, положит программу в
   `C:\FinanceBot` и настроит автозапуск вместе с Windows. Займёт 2–5 минут.
   В конце он напишет «Осталось вписать настройки» — так и должно быть.
5. **Включите страницу настроек**:
   ```
   powershell -ExecutionPolicy Bypass -File C:\FinanceBot\deploy\windows\settings.ps1
   ```
   Придумайте пароль (не короче 10 символов; при вводе он не виден). Скрипт
   откроет порт 8765 в брандмауэре Windows и покажет адрес `https://IP:8765`.
   - Адрес вида 10.x, 172.x или 192.168.x — внутренний. С телефона нужен
     внешний IP: он есть в панели хостинга (тот же, по которому вы подключаетесь по RDP).
   - Если у хостинга есть свой файрвол в панели — откройте там порт 8765 (TCP).
6. **Заполните настройки с телефона.** Откройте адрес. Браузер предупредит
   о сертификате: «Дополнительно» → «Перейти на сайт». Войдите по паролю,
   впишите ключ Claude API, токен бота (и тестового бота), нажмите
   «Проверить и сохранить».
7. **Добавьте пользователей.** Каждый из двоих пишет боту «привет» — бот
   ответит «Доступ закрыт. Ваш Telegram id: …». Впишите эти числа на
   странице в поля «Пользователь 1» и «Пользователь 2» и снова сохраните.
   (Кнопка «Кто писал боту» работает, только пока бот ещё не запущен.)
8. **Готово.** Каждый пишет боту `/help` и добавляет карты:
   `/addcard Сбер 1234 Сбер`, для бизнес-счёта — `/addcard ПСБ 4987 ПСБ бизнес`.

## Как это устроено

- Программа — в `C:\FinanceBot`. Доступ к папке есть только у системы
  и администраторов: там токены и базы.
- Задание Планировщика **FinanceBot** запускается вместе с Windows и держит
  работающими боевой бот, тестовый бот и страницу настроек. Если что-то
  упадёт, оно перезапустится через 10 секунд; если остановится само задание —
  Планировщик поднимет его в течение 5 минут. Останавливать — только через
  `stop.ps1` (обычная остановка задания оставляет ботов работать без присмотра).
- Нужен Python «для всех пользователей» (в Program Files). Если найден только
  Python в профиле пользователя, установщик поставит общий сам.
- Задание **FinanceBot-Backup** каждый день в 03:30 делает копию баз в
  `C:\FinanceBot\backups` (хранятся 30 дней). Копию стоит также уносить с сервера.
- Журналы: `C:\FinanceBot\logs` (`bot.log`, `bot-test.log`, `settings.log`,
  `supervisor.log`).

## Полезные команды (PowerShell от имени администратора)

| Что | Команда |
|---|---|
| Состояние и последние строки журналов | `powershell -ExecutionPolicy Bypass -File C:\FinanceBot\deploy\windows\status.ps1` |
| Сменить пароль страницы | `... settings.ps1 -Password` |
| Выключить страницу и закрыть порт | `... settings.ps1 -Off` |
| Другой порт | `... settings.ps1 -Port 9443` |
| Остановить всё | `... stop.ps1` |
| Запустить снова (и после перезагрузки бот остаётся остановленным, пока не запустите) | `... stop.ps1 -Start` |
| Бэкап вручную | `Start-ScheduledTask FinanceBot-Backup` |

(`...` — это `powershell -ExecutionPolicy Bypass -File C:\FinanceBot\deploy\windows\`)

## Восстановление из бэкапа

Бэкап лежит в `C:\FinanceBot\backups`: базы — `finance-<Telegram id>-<дата>.db`
(30 дней), скриншоты — папка `receipts-<Telegram id>` (зеркало), настройки —
`env-latest.txt`. Копию этой папки стоит регулярно уносить с сервера (флешка,
облако): бэкап на том же диске не спасёт от поломки диска.

Восстановить базу пользователя (PowerShell от имени администратора):
```
powershell -ExecutionPolicy Bypass -File C:\FinanceBot\deploy\windows\stop.ps1
Copy-Item C:\FinanceBot\backups\finance-<id>-<дата>.db C:\FinanceBot\data\users\<id>\finance.db -Force
Remove-Item C:\FinanceBot\data\users\<id>\finance.db-journal -ErrorAction SilentlyContinue
Copy-Item C:\FinanceBot\backups\receipts-<id>\* C:\FinanceBot\data\users\<id>\receipts\ -Recurse -Force
powershell -ExecutionPolicy Bypass -File C:\FinanceBot\deploy\windows\stop.ps1 -Start
```
Записи, сделанные после этого бэкапа, пропадут — пришлите их скриншоты ещё раз.
Сервер новый: установите бота (шаги выше), затем верните `.env` из
`env-latest.txt` (переименуйте в `C:\FinanceBot\.env`) и базы, как выше.

## Если не пускает на страницу настроек

- **Забыли пароль** или «вход закрыт на час» (кто-то из интернета перебирал
  пароли): по удалённому рабочему столу выполните
  `powershell -ExecutionPolicy Bypass -File C:\FinanceBot\deploy\windows\settings.ps1 -Password`
  — новый пароль, страница перезапустится и блокировка снимется.
- Страница не нужна постоянно — выключите её (`settings.ps1 -Off`) и включайте,
  когда надо поменять настройки: так её никто не будет перебирать.

**Обновление до новой версии**: распакуйте новый архив и снова выполните
шаг 4. Перед заменой кода установщик сделает бэкап; данные и настройки не
трогаются.

**Если что-то не работает** — выполните `status.ps1` (команда выше) и
пришлите вывод.

## Отличия от установки на Linux

- Тестовый бот отделён от боевых данных проверками в самой программе
  (отдельная папка, запрет стирать боевые данные), но не правами системы:
  на Windows оба бота работают под одной системной учётной записью.
- Страница настроек работает под той же учётной записью, что и боты.
- Установка для Windows ни разу не запускалась на настоящей Windows:
  проверена логика (супервизор, бэкап, настройки, страница) и сами скрипты
  на PowerShell 7 с подменой команд Windows. Если на каком-то шаге ошибка —
  пришлите её текст.
