# Финансовый помощник — Telegram-бот

Учитывает расходы на бизнес, оплаченные с личных карт. В конце месяца по
выпискам показывает, сколько по каждой карте пришло и ушло, сколько из этого
на бизнес, а сколько на личное.

Отдельный проект, с Sync Admin не связан: свой код, своя база, своя служба.

## Как пользоваться

**В течение месяца.** Оплатили что-то для бизнеса с личной карты — пришлите
боту скриншот из банка или фото чека. Можно добавить подпись, например
«реклама ВК». Бот сам распознаёт сумму, дату, получателя, карту (по последним
цифрам или по банку) и статью расхода. Переспрашивает, только если чего-то
не хватает:

- не видно карту — кнопки с вашими картами;
- статья неочевидна — кнопки со статьями, предложенная отмечена ✓;
- покупка похожа на личную — «Бизнес / Личное»;
- на скриншоте поступление — «Возмещение от бизнеса / Не записывать»;
- оплата в валюте — сколько списано в рублях;
- та же сумма, дата и карта уже записаны — «повтор или другая оплата».

После записи под карточкой есть кнопки «Статья», «Карта», «Это личное»
и «Удалить» — ошибку можно исправить сразу. Несколько скриншотов подряд
встают в очередь, вопросы задаются по одному. Расход можно записать
и текстом: «3500 доставка СДЭК с Т-Банка вчера».

**В конце месяца — сверка.**

1. `/sverka` → выбрать месяц → выбрать карту.
2. Прислать выписку по этой карте: PDF, скриншоты, Excel или CSV, можно
   несколькими сообщениями. Если выписки нет, достаточно написать
   «пришло 120000, ушло 95000».
3. `/done` — бот покажет итог по карте:
   - **Пришло** и **Ушло** — по выписке;
   - **на бизнес** — сумма ваших записей по этой карте;
   - **на личное** — всё остальное, что ушло, без переводов между своими
     картами;
   - ⚠️ записи, которых нет в выписке (обычно выбрана не та карта);
   - списания, которые сейчас считаются личными. Если среди них есть бизнес
     (забыли прислать скриншот), отправьте `/biz 12 15`, и они станут
     бизнес-расходами.
4. Повторить для остальных карт.
5. `/itog` — общий свод: по каждой карте пришло/ушло/бизнес/личное,
   бизнес-расходы по статьям и сколько бизнес должен вам вернуть (бизнес-расходы
   минус полученные возмещения). К своду прикладывается Excel-файл: лист
   «Свод», все бизнес-расходы с путями к скриншотам и лист расхождений.

Запись из выписки и запись со скриншота считаются одной операцией, если сумма
совпадает до копейки, а даты расходятся не больше чем на 3 дня. Повторно
присланный кусок выписки не задваивается.

Прочие команды: `/list 2026-02` — записи за месяц, `/fix 42` — исправить запись, `/cards`, `/addcard Сбер 1234 Сбер`,
`/delcard 2`, `/cats`, `/addcat Обучение`, `/cancel`, `/help`.

## Старт задним числом (например, с 1 января)

Скриншотов за прошлые месяцы обычно нет, зато есть выписки. Порядок такой:

1. Добавьте три карты (`/addcard …`).
2. Скачайте в каждом банке одну выписку по карте за весь период,
   с 1 января по сегодня: PDF или Excel.
3. `/sverka` → «📚 Выписка за несколько месяцев» → карта → пришлите файл →
   `/done`. Операции сами разложатся по месяцам. Бот покажет итоги по каждому
   месяцу и список списаний, **похожих на бизнес** (СДЭК, рекламные кабинеты,
   сервисы маркетплейсов, поставщики…), с предложенной статьёй.
4. Проверьте список: лишнее уберите `/notbiz 12 15`, затем нажмите
   «✅ Записать все как бизнес». Бот запишет их одной сводкой, без вопросов
   по каждому.
5. Бизнес-расходы, которые бот не распознал, найдите через
   `/vypiska 2026-03` (все списания месяца, которые сейчас считаются личными)
   и добавьте `/biz 7 9`. Статью бот спросит, если не сможет её угадать.
6. Повторите для остальных карт и получите свод: `/itog 2026` — с января
   по текущий месяц, по месяцам и статьям. В своде есть сумма, которую бизнес
   должен вам на сегодня, нарастающим итогом.

Если за прошлые месяцы всё-таки есть скриншоты, просто пришлите их. Дата
берётся со скриншота, файл попадает в папку месяца оплаты.

Кнопками в `/sverka` можно выбрать любой из последних 12 месяцев. Более
ранний месяц задаётся вручную: `/sverka 2025-06`.

Не присылайте две выписки с пересекающимися датами по одной карте. Одинаковые
строки бот не задвоит, но банк может по-разному написать описание одной и той
же операции в двух файлах, и тогда она посчитается дважды. Чтобы перезагрузить
месяц, выберите его в `/sverka` и нажмите «Загрузить заново».

## Особенности банков (по реальным образцам)

**Номера карт.** В квитанциях часто стоит номер счёта, а не карты: у банка
«Россия» это «Счет списания 4081…0723», у ВТБ — «Мастер-счет •2928», хотя
в другой квитанции той же карты будет «Карта для жизни •8445». Поэтому у карты
в боте может быть несколько номеров. Если бот видит незнакомый номер, он один
раз спросит, какая это карта, и запомнит ответ. Номера можно задать и сразу:
`/addcard ВТБ 8445 2928 ВТБ`. Если на скриншоте номера нет, карта определяется
по банку, в том числе по названию приложения: «ABR Direct» — это банк «Россия».

**Категории банка не учитываются.** Подписи вроде «Развлечения» или «Услуги»
банк ставит автоматически, поэтому бот на них не опирается. Статью он
предлагает сам, а если сомневается, спрашивает.

**Банк «Россия», выписка «Список операций».** Получатель в ней не указан,
у всех оплат одно описание «Оплата по QR-коду через СБП». Поэтому:
- предложений «похоже на бизнес» по такой выписке почти не будет;
- операции различаются по дате, **времени** и сумме, и бот показывает время
  в списках `/vypiska` и после `/done`;
- **для старта задним числом** удобнее открыть в ABR Direct «Историю операций»
  и прислать боту квитанции нужных бизнес-платежей. Бот запишет их с их
  датами, а при сверке они сами сопоставятся с выпиской.

Комиссию, которая идёт внутри операции отдельной суммой («Комиссия −110 ₽»),
бот записывает отдельным списанием, чтобы итог «ушло» сошёлся.

**ВТБ, экран «История».** Верхние плашки «Расходы в сентябре» и «Поступления
в сентябре» — это готовые итоги месяца. Скриншот этого экрана можно прислать
в `/sverka` вместо выписки или вместе с ней. Если прислать его вне сверки, бот
подскажет открыть `/sverka`. Учтите, что ВТБ считает эти итоги по всем своим
картам и счетам сразу.

## Установка на сервер

Нужны:
- **токен бота** — в Telegram у @BotFather: `/newbot`;
- **ключ Claude API** — на https://platform.claude.com в разделе API Keys.
  Распознавание оплачивается по тарифу API.

```bash
sudo useradd --system --home /opt/finance-bot finance-bot
sudo mkdir -p /opt/finance-bot && sudo cp -r finance requirements.txt /opt/finance-bot/
cd /opt/finance-bot
sudo python3 -m venv venv && sudo venv/bin/pip install -r requirements.txt
sudo cp /путь/к/finance_assistant/.env.example .env && sudo nano .env   # токены
sudo chown -R finance-bot: /opt/finance-bot && sudo chmod 600 .env
sudo cp /путь/к/finance_assistant/deploy/finance-bot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now finance-bot
journalctl -u finance-bot -f
```

Первый запуск:
1. Напишите боту что угодно. Он ответит «Доступ закрыт. Ваш Telegram id: …».
2. Впишите этот id в `ALLOWED_USER_IDS` в `.env` и выполните
   `sudo systemctl restart finance-bot`.
3. Добавьте карты: `/addcard Сбер 1234 Сбер`, `/addcard Тинькофф 5678 Т-Банк`,
   `/addcard Альфа 9012 Альфа-Банк`. Последние 4 цифры помогают боту узнавать
   карту по скриншоту.

Бот сам опрашивает Telegram, поэтому ни домен, ни открытый порт ему не нужны.
Запустить его можно на любой машине с интернетом, в том числе на VPS
Sync Admin.

**Бэкап:** всё хранится в `FINANCE_DATA_DIR`: база `finance.db` и скриншоты
в `receipts/ГГГГ-ММ/`. Эту папку и нужно копировать.

## Безопасность и данные

- Бот отвечает только пользователям из `ALLOWED_USER_IDS`. Остальным он
  сообщает только их собственный id.
- Скриншоты и выписки отправляются на распознавание в Claude API (Anthropic).
  В Telegram они тоже проходят через серверы Telegram. Номера карт целиком
  не нужны: боту хватает последних 4 цифр.

## Разработка

```bash
cd finance_assistant
python3 -m venv venv && venv/bin/pip install -r requirements.txt pytest
venv/bin/python -m pytest -q
```

Тесты подменяют Claude фейковым распознавателем и Telegram не используют.

- `finance/flow.py` — весь сценарий диалога (вопросы, кнопки, сверка), без Telegram;
- `finance/bot.py` — обвязка python-telegram-bot;
- `finance/recognize.py` — запросы к Claude: скриншот → платёж, выписка → операции;
- `finance/reconcile.py` — сопоставление с выпиской и месячный свод;
- `finance/report.py` — тексты и Excel;
- `finance/storage.py` — SQLite.

## Что не проверено

- Распознавание на настоящих скриншотах и выписках: в среде разработки не было
  ключа Claude API. Проверено только, что запрос правильно формируется
  и ответ правильно разбирается. Первые скриншоты стоит проверить глазами.
- Насколько точно модель отбирает «похожие на бизнес» списания в выписке.
  Это только предложение: список нужно проверить перед нажатием кнопки.
- Работа бота с настоящим Telegram: не было токена. Логика диалога покрыта
  тестами, а подключение к Telegram собрано по документации python-telegram-bot 22.
