# Помощник по ведению финансов

Отдельный от Sync Admin проект: учёт личных или семейных денег в командной
строке. Он не использует код приложения синхронизации и его базу.
Нужен только Python 3.10+, сторонних зависимостей нет. Данные хранятся в одном
файле SQLite (по умолчанию `~/.finance_assistant.db`; другой путь можно задать
через `--db` или переменную `FINANCE_DB`).

## Что умеет

- **Счета**: карта, наличные, вклад и т. п., с начальным остатком. Показывает
  текущие остатки и итог.
- **Операции**: доход, расход, перевод между своими счетами. Дату можно указать
  как `2026-09-05` или `05.09.2026`, сумму — как `1 234,50`.
- **Категории**: при первом запуске создаётся базовый набор (Продукты, ЖКХ,
  Транспорт, Зарплата…), свои можно добавить. Категорию дохода нельзя
  по ошибке указать у расхода, и наоборот.
- **Отчёт за месяц**: доходы и расходы по категориям с долями, разница
  и процент отложенного от дохода.
- **Бюджеты**: лимит на категорию расходов на месяц. `!!` — лимит превышен,
  `!` — деньги уходят быстрее, чем идёт месяц (например, 80 % лимита на
  10-й день). Лимиты можно перенести на следующий месяц одной командой.
- **Регулярные операции**: аренда, подписки, зарплата. `recurring apply`
  проводит те, чей день уже наступил. Повторный запуск ничего не дублирует;
  «31-е число» в коротком месяце — это последний день месяца.
- **Динамика** доходов и расходов по месяцам.
- **CSV**: выгрузка всех операций и загрузка из файла. Загрузка выполняется
  целиком или никак: если в одной строке ошибка, в базу не попадает ничего.
  Недостающие счета и категории создаются сами.

Деньги хранятся в копейках (целые числа), поэтому ошибок округления нет.

## Быстрый старт

```bash
cd finance_assistant
alias finance="python3 -m finance"

finance account add Карта --balance 20000
finance account add Наличные

finance income 90000 Зарплата -a Карта -d 01.09.2026
finance expense 1250,50 Продукты -a Карта -n "Пятёрочка"
finance transfer 5000 --from Карта --to Наличные

finance budget set Продукты 15000
finance budget set "Кафе и рестораны" 4000
finance recurring add Аренда 30000 ЖКХ -a Карта --day 5
finance recurring apply

finance report            # итоги текущего месяца + бюджет
finance report -m 2026-08 # за другой месяц
finance list -m 2026-09 -c Продукты
finance account list
finance trend --months 6
finance budget copy 2026-09 2026-10

finance export backup.csv
finance import bank.csv   # колонки: date,type,amount,account,category,to_account,note
```

Ошибочную операцию можно удалить по номеру из `finance list`:
`finance delete 12`. Полная справка: `finance --help` и
`finance <команда> --help`.

## Тесты

```bash
cd finance_assistant
pip install pytest
python3 -m pytest -q
```

## Устройство

- `finance/money.py` — разбор и форматирование сумм.
- `finance/ledger.py` — схема SQLite и вся логика (`Ledger`).
- `finance/cli.py` — командная строка. Она только вызывает методы `Ledger`.
