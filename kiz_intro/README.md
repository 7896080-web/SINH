# «Ввод в оборот» — коды вне Lamoda

Отдельная программа рядом с «Маркировкой» (решение заказчика 05.10.2026:
основную программу не меняем). Своя папка, база, ключ шифрования, порт
**8003** (8001 — «Маркировка», 8002 — «Репрайсер»), ярлык «Ввод в оборот». 1С не участвует.

## Что делает

1. **ИП** — их несколько. У каждого:
   - свой вход в ЧЗ сертификатом (ИНН сертификата обязан совпасть с ИНН ИП);
   - свой справочник карточек Нацкаталога (запрошены токеном этого ИП);
   - свои партии.
2. **Загрузка PDF из ЛК ЧЗ** (`order_…_gtin_…_quantity_N.pdf`).
   - Полный код есть только в картинках DataMatrix: страницы рендерятся
     (pypdfium2), коды читает zxing-cpp.
   - Проверки: только полные коды, без повторов, не загружены раньше, число
     равно `quantity_N` из имени файла.
   - Коды хранятся зашифрованно. Карточки НК для GTIN партии запрашиваются сразу.
3. **Статусы кодов** (`/cises/info`) и карточки НК — кнопкой
   «Проверить статусы и карточки НК»; страница партии сама обновляется раз
   в минуту, пока не всё в обороте.
4. **Ввод в оборот** (`LP_INTRODUCE_GOODS`, собственное производство, ИП —
   производитель и владелец):
   - только коды «Нанесён»;
   - ТН ВЭД и разрешительный документ — из карточки НК в справочнике ИП;
   - дату производства вводит человек;
   - перед подписью — сводка; подпись плагином КриптоПро.
   - Нет ответа ЧЗ — документ «неизвестно», коды заняты до решения человека
     (повтора без решения нет).
5. **Проверка** — по статусам кодов «в обороте» и итогу документа.
6. **Этикетки 58×40 (PDF)** — как в «Маркировке»: GS1 DataMatrix, каждая
   этикетка читается декодером до выдачи. Главная строка — название из
   карточки НК. Шаблон строк и модуль — на главной.
7. **Коды (.txt)** — когда все коды партии в обороте: полный код на строку,
   GS внутри, CRLF, без BOM (как выдаёт СУЗ).
8. **Коды для УПД (.csv)** — когда все коды партии в обороте: файл для загрузки
   кодов маркировки в УПД в Диадоке, по шаблону
   `номер,наименование,цена,количество,ОКЕИ,НДС,КИЗ,код,код,…`. Строка — на
   GTIN (наименование из карточки НК этого ИП), коды — короткие КИ без
   криптохвоста, каждый в своей колонке; код с запятой — в кавычках. Цена и НДС
   пустые — они уже в УПД. UTF-8 без BOM, LF. **Номер строки в файле — номер
   товарной строки УПД:** порядок строк в УПД должен совпадать с порядком GTIN в
   файле (по порядку загрузки кодов).

Ключ `KIZ_SECRETS_KEY` из `C:\kiz_intro\.env` — в хранилище паролей.

## Обновление

```powershell
robocopy C:\dev\sinh\kiz_intro C:\kiz_intro /E /XD .venv logs backups __pycache__ .pytest_cache /XF .env kiz.db kiz.db-wal kiz.db-shm
powershell -ExecutionPolicy Bypass -File C:\kiz_intro\deploy\update.ps1
```

Скрипт останавливает программу по порту, снимает копию базы в `backups\`,
ставит зависимости, гоняет тесты и запускает. Программа запущена от
администратора и не остановилась — обновление стоп (база цела): снять
`python` в Диспетчере задач и повторить. Запускать программу — ярлыком или
из обычного PowerShell.
