name: wb-autopilot
description: Пробный прогон автопилота ставок WB (wb_bids.py), проверка плана и применение после согласия.
disable-model-invocation: true
---

1. Запусти `python wb_bids.py` (пробный прогон — ничего не меняет).
2. Проверь план на странности и перескажи по-русски:
   - резкие повышения ставок, ставки у товаров без остатка на складах WB;
   - минус-фразы по главным запросам товара (например «джемпер мужской» для джемпера) — спроси, оставить ли их
     в рекламе (если да — добавить в `PROTECT` в `wb_bids.py`);
   - дневные лимиты ниже рекомендуемых WB;
   - строки «WB не вернул текущие минус-фразы — не трогаю»: если так по всем товарам, WB, вероятно, отдаёт список
     в другом виде — разобраться в коде до `--apply`, иначе минус-фразы не будут обновляться;
   - строки с «!» о незагруженных данных: при них `--apply` откажется применять — предложи запустить позже.
3. Спроси явное согласие. Только после «да» запусти `python wb_bids.py --apply`.
4. Напомни про откат: `python wb_bids.py --rollback` возвращает всё, что изменил последний запуск.
