Официальные отчёты по API

Wildberries — еженедельные отчёты реализации из finance-api (тот же отчёт, что в ЛК «Финансовые отчёты»), вместе с «Итого к оплате» WB для сверки. Нужен токен с категорией «Финансы» (поле на «API-ключах»). WB отдаёт один запрос в минуту, поэтому загрузка за несколько недель идёт десятки минут — в фоне. Яндекс KIT — финансового отчёта у KIT нет; отчёт за период собирается из официальных данных заказов: доставленное за вычетом отказов, стоимость доставки для магазина. Lamoda — финансовых отчётов в API Lamoda нет. Еженедельные отчёты приходят письмом и забираются с почты сами (настройка — на «API-ключах»): это предварительные данные. Отчёт комиссионера — итоговый документ: при его загрузке (файлом ниже или письмом) предварительные данные за его период заменяются им, и в 1С уходит только он.
