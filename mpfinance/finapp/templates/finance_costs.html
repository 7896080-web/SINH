Сайт на Яндекс KIT

«Сумма» в выгрузке AWER CRM — до комиссии; к перечислению идёт за её вычетом. Ставка применяется при загрузке отчёта: уже загруженный отчёт пересчитается, если удалить его и загрузить снова. Если продажи берутся из AWER CRM, загрузка KIT по API берёт из заказов только доставку — иначе продажи посчитались бы дважды.

Сейчас: {{ tax_text }}{% if tax_effective is not none %} — всего {{ '%.2f'|format(tax_effective)|replace('.', ',') }}% реализации{% endif %}. НДС считается внутри цены (из 105 ₽ — 5 ₽), УСН «доходы» — с реализации без НДС. Реализация у WB — «Вайлдберриз реализовал» (что заплатил покупатель после скидки WB), а не цена продавца, от которой считается выручка.
