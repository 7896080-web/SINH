## Находки: безопасность (сырые, до проверки)

Модель угроз: служба на 127.0.0.1:8003, вход по RDP, 1–2 оператора; на том же
127.0.0.1 — sync_admin:8000 и «Репрайсер». Закрыто и проверено: доступ (все 38
маршрутов), SQL-инъекции, XSS, шифрование секретов, сессия, только-чтение базы
Sync Admin.

- **Б1 (ВАЖНО)** CSRF: единственная защита — SameSite=Lax, а он порт не
  различает. POST со страницы на 127.0.0.1:<другой порт> проходит
  (воспроизведено в Chromium). Правка: проверка Origin на POST.
- **Б2 (ВАЖНО)** Перевод строки в имени склада 1С проходит проверку (запрещён
  только «|») и даёт в файле заданий вторую строку — отдельную команду для 1С.
  Правка: запрет \r \n (и в сохранении настроек, и перед отправкой).
- **Б3 (ВАЖНО)** Выгрузки Excel: значение, начинающееся с «=», становится
  формулой (openpyxl). Правка: текстовые ячейки — строкой принудительно.
- **Б4 (ЗАМЕЧАНИЕ)** Почта доверяет полю «От»: письмо «от b2b@lamoda.ru» может
  прислать кто угодно. Денег не двигает (в 1С только по кнопке).
- **Б5 (ЗАМЕЧАНИЕ)** /logout — GET.
- **Б6 (ЗАМЕЧАНИЕ)** Предел размера загрузки (read_upload, 40 МБ) написан, но не
  вызывается ни одной загрузкой.

## Находки: цепочки (сырые, до проверки)

- **Ц1 (КРИТИЧНО)** Автоплан KIT: окно «две полные недели» сдвигается на неделю,
  ключ — по периоду, поэтому каждая неделя оказывается в ДВУХ отчётах (доставка
  вдвое; в режиме «продажи из API» — продажи вдвое, и обе копии уходят в 1С).
  Правка: недельные заявки (ключ по неделе) + отказ в отправке при пересечении
  строк с уже отправленным отчётом.
- **Ц2 (ВАЖНО)** Предупреждения о задвоении на пути API теряются (в сообщение
  заявки не попадают); отчёт без кабинета сравнивается только с отчётами без
  кабинета. WB: файл без «№» в имени + тот же отчёт по API = два отчёта.
- **Ц3 (ВАЖНО)** Переключение «откуда продажи KIT» убирает только отчёт за точно
  то же окно; остальные отчёты прежнего режима остаются (вдвое).
- **Ц4 (ВАЖНО)** Ключ отчёта без номера — по площадке+кабинету+периоду: файл
  Яндекс Пэй или CRM за месяц занимает ключ, и KIT по API за тот же месяц молча
  не ложится («уже отправлен в 1С» — неправда).
- **Ц5 (ВАЖНО)** Lamoda: неделя с почты (кабинет не указан) и та же неделя руками
  с кабинетом — разные номера, неделя вдвое до отчёта комиссионера.
- **Ц6 (ВАЖНО)** Ответ 1С не привязан к конкретной отправке (поздний ERROR на

- **Ц7 (ВАЖНО)** «Пересопоставить» на отчёте, уже загруженном в 1С, молча

- **Ц8 (ВАЖНО)** Ручная себестоимость из Excel без даты ложится с 2000-01-01 и

- **Ц9 (ВАЖНО)** Ежедневный перезабор KIT стирает ввод оператора на отчёте

- **Ц10 (не подтверждено)** Комиссия 3,5% CRM и детализация Яндекс Пэй, вероятно,

## Находки: формулы (сырые, до проверки)

- **Ф1 (КРИТИЧНО)** = Ц1: автоплан KIT задваивает неделю (воспроизведено и здесь:
  доставка 250 ₽ за октябрь показана 500 ₽).
- **Ф2 (ВАЖНО)** = Ц8: ручная себестоимость без даты проигрывает 1С (1500 ₽ →
  считается 900 ₽), и 1С продолжает её обновлять.
- **Ф3 (ВАЖНО)** Файл заказов KIT: статус FULL_REFUND (отказ при получении) по
  подстроке «refund» становится ВОЗВРАТОМ с выручкой −цена и уходит в 1С; «Отказ
  при получении», «Не получен», «Не доставлен» по подстроке становятся ПРОДАЖЕЙ.
  Правила файла и API расходятся (FROZEN).
- **Ф4 (не подтверждено)** = Ц10: 3,5% CRM + Яндекс Пэй — комиссия дважды.
- **Ф5 (ВАЖНО)** УСН «доходы − расходы»: налог бывает отрицательным в итоге
  (занижает убыток); минимальный налог 1% не учтён.
- **Ф6 (не подтверждено)** WB лояльность: «компенсация скидки» у возврата не меняет
  знак; возможно, она уже внутри «К перечислению» (двойной учёт).
- **Ф7 (не подтверждено)** Файл заказов KIT: доставка уровня заказа на каждой
  строке товара складывается.
- **Ф8 (ВАЖНО)** = Ц11: курс ЦБ любой давности подставляется молча; ручной курс
  почти не применяется.
- Замечания: себестоимость возврата по курсу даты возврата (прибыль из ничего);
  единая форма — пустая «Комиссия» даёт 0, расход с минусом увеличивает выплату;
  WB возврат с пустым «Типом документа» — знак +; parse_money("1,234") = 1,23 ₽
  молча; центы себестоимости 1С округляются к чётному; Lamoda — abs() скрывает
  несогласованные знаки; смысл «суммы к перечислению» KIT в 1С зависит от
  настройки.
