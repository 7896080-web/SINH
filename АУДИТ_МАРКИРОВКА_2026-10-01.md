# Аудит программы «Маркировка и поставки» — 01.10.2026

Полный аудит кода `marking/` после переноса этапа 4 (вход в ЧЗ, коды поставки)
в ветку. Четыре направления параллельно, только чтение, сценарии
воспроизводились на временной базе с подменой ЧЗ и 1С:

1. сопоставления (файл поставки ↔ каталог ↔ 1С ↔ GTIN ↔ FBO ↔ коды);
2. жизненный цикл поставки и обмен с 1С;
3. этап 4 — Честный знак (сверка байт в байт с рабочей программой
   заказчика kiz-tool, двойные действия, потеря кодов, безопасность);
4. связность страниц, маршрутов, шаблонов, миграций и документов.

Итог: **исправлено всё критичное и почти всё важное**, на каждое исправление —
тест (`marking/tests/test_audit_fixes.py`). Тесты: 204 passed, 1 skipped, в
поясе Москвы и в UTC (`TZ=UTC0` на Windows работает).

Ниже: находка → что сделано. «Открыто» — сознательно не трогали, с причиной.

## Открыто — сознательно, с причиной

- **Ограничитель запросов на ИНН для всех обращений к ЧЗ** (ТЗ 7.2) и пауза
  по 429 для заказа/документов — сейчас лимит НК и пауза опроса статусов.
  Для первых живых поставок нагрузка мала; делать вместе с «вводом при
  готовности».
- **`/product/info`**: владелец GTIN, `goodMarkFlag`/`goodTurnFlag`, срок
  разрешительного документа перед вводом; **«ввод при готовности»**
  автоматически; **файл поставки xlsx с кодами** (ТЗ 6.3); **проверка УПД в ЧЗ**;
  статус «Коды готовы»; заказ вне поставки — следующие шаги этапа 4.
- **Один документ ввода на поставку** (kiz-tool — по артикулу). Если ЧЗ
  отклоняет документ целиком, ошибка одного артикула задержит все. Решить по
  первому живому прогону.
- **CSRF/Host**: SameSite=lax + JSON закрывают чужие сайты; страницы на
  других портах `127.0.0.1` (sync_admin) формально могут слать формы.
  `TrustedHostMiddleware` и проверка Origin — отдельной правкой.
- **`cadesplugin_api.js` грузится с cryptopro.ru** — положить в `/static`
  после согласования версии.
- **Склад проверки и склад документа в модуле 1С** берутся из разных мест
  (по умолчанию совпадают) и **параллельные сеансы обработки** — правка
  модуля 1С, только через Конфигуратор и тесты sync_admin.
- **Повтор номера поставки после восстановления копии** — описать в порядке
  восстановления (сдвинуть нумерацию вручную).
- **`update_workstation.ps1`**: каталог `tools\` исключён из обновления, а
  там лежит и `plugin_check.html` из репозитория — его правки не доезжают;
  порядок отката при красных тестах после миграции не описан.
- Пароль первого пользователя в установщике виден на экране и в списке
  процессов.
- `python-multipart`/`starlette` — известные DoS при разборе multipart
  (программа слушает только 127.0.0.1).
- Мелочи сопоставлений: предупреждения строк не пересчитываются после
  удаления строки; этикетка без данных каталога без предупреждения; GTIN кода
  без пары не встаёт в очередь НК; FBO без номера поставки проходит.
